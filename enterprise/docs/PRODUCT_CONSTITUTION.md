# Constitución del producto — CO2 Evidence Ledger RC7 STAGE

1. Producto: evidencia trazable B2B para declaraciones climáticas responsables, no criptoactivo, token, mercado ni acreditador.
2. Unidad probatoria: actividad, cantidad, unidad, factor aportado con referencia, cálculo exacto en Go, expediente, evidencia binaria, huella y revisión interna.
3. Diferenciar prueba de bytes, cadena de cambios, autenticidad de origen, suficiencia metodológica, certificación de terceros e inmutabilidad externa; **las últimas cuatro no se presumen**.
4. Prohibidos créditos de carbono vendidos, emitidos, retirados o transferidos; datos inventados sin identificador SINTÉTICO; pantalla que indique éxito si falla PostgreSQL.
5. Datos por organización; roles owner, reviewer, viewer; altas de usuario solo por CLI; control de pertenencia previo a toda operación. En fase 00 la seguridad definitiva exige revisión de terceros y pruebas E2E con PostgreSQL auténtico.
6. No reescribir eventos históricos: modificaciones futuras deben agregarse como nuevos eventos. SHA-256 sin anclaje externo no es sello de tiempo confiable ni blockchain.
7. RC7 usa cliente PostgreSQL ligero de laboratorio y PBKDF2-HMAC-SHA256 como transición. **La librería PostgreSQL auditada y Argon2id son puertas de producción todavía NO superadas.**
8. El diseño web HTML/JS de RC7 es funcional en fase de laboratorio y NO acredita todavía el frontend React/TypeScript objetivo especificado ni WCAG 2.2 AA.
9. La biblioteca RC6 no se elimina y no se importa silenciosamente. Una migración posterior debe distinguir historial legado y nuevo registro.
10. Promoción vedada sin DB real, pruebas de aislamiento A/B, restauración, cifrado, seguridad, revisión de configuración RGPD, E2E navegador, aprobación formal y acta de aceptación.
