## Bloqueos para evaluación completa

1. Falta servidor PostgreSQL real accesible desde este contenedor; la red no permite obtener drivers externos ni paquetes. Por ello no hay pruebas de creación, reinicio, backup/restore o aislamiento A/B contra una base auténtica.
2. El cliente PostgreSQL implementado para laboratorio no ha sido auditado frente a servidores auténticos, negociación TLS y SCRAM (solo pruebas del protocolo con servidor simulado). Sustituir por un driver mantenido y probado antes de producción.
3. PBKDF2-HMAC-SHA256 con sal aleatoria y 310.000 iteraciones es el mecanismo temporal; requisito definitivo del proyecto: Argon2id. No afirmar que Argon2id está implementado.
4. Seguridad de autenticación, autorización, CSRF, sesión y aislamiento no probada aún con PostgreSQL y navegadores reales. No cumple todavía aceptación multi-tenant.
5. HTML/JavaScript nativo es interfaz provisional, no React/TypeScript/Vite objetivo ni certificación WCAG 2.2 AA.
6. No se ha configurado infraestructura Cloudflare/Vercel STAGE, ni endpoints externos, ni secretos, ni backups, ni auditoría externa, ni protección de datos legalmente validada.
7. Las funciones de integridad no constituyen blockchain distribuida, sello temporal ni firma confiable; un administrador privilegiado puede reconstruir todo el historial.
